# Code reference

This section documents **every public item** in the `steamlogger` crate, module
by module: signatures, behaviour, error cases, invariants and the tests that
cover them.

```toml title="Cargo.toml"
[package]
name = "steamlogger"
version = "0.1.0"
edition = "2021"
license = "MIT"

[lib]
name = "steamlogger"
path = "src/lib.rs"

[[bin]]
name = "steamlogger"
path = "src/main.rs"
```

The crate builds both a library and a binary from the same source tree. The
library is the reusable part; the binary is one way to wire it together.

## Conventions used in this reference

- **Signatures** are copied verbatim from the source; `self` receivers show
  mutability exactly as declared.
- **Errors** sections list the `anyhow` context strings you will actually see
  on stderr.
- **Panics** sections exist only where the code can panic (there are two such
  places in the crate, both documented).
- Private helpers are documented when they carry meaningful behaviour —
  `Tracker::close_at`, `storage::temp_path`, `a2s::parse_cstr`,
  `client::chunks` — and marked *(private)*.

## Dependencies

| Crate | Version | Used for |
| --- | --- | --- |
| `anyhow` | 1 | Error type and `.context()` messages everywhere |
| `chrono` | 0.4 (`serde`) | RFC 3339 local timestamps in `main::now` |
| `ctrlc` | 3 | `SIGINT` handler |
| `reqwest` | 0.12 (`blocking`, `json`, `rustls-tls`, no default features) | HTTPS to the Steam Web API |
| `serde` | 1 (`derive`) | Config and log (de)serialisation |
| `serde_json` | 1 | JSON parsing and pretty printing |
| `toml` | 0.8 | Config parsing |

No async runtime, no OpenSSL, no database driver.
